Model Hibrid GIS-AHP & GeoAI untuk Penilaian Kesesuaian Tanah Padi (Kota Belud)

Automasi Ruang, Pemodelan Keputusan Multikriteria (MCDM), dan Pembelajaran Mendalam (*Deep Learning*)

GIS & Remote Sensing MCDM-AHP PyTorch & GeoAI Python / ArcPy

📊 Project Overview

Projek ini membangunkan pangkalan data spatial berskala mikro di Daerah Kota Belud bagi mengenal pasti dan menilai kawasan kesesuaian tanah terbiar untuk penanaman semula padi jelapang. Pendekatan hibrid menggabungkan penilaian faktor fizikal dan sosio-ekonomi secara saintifik.

Sistem ini disokong sepenuhnya oleh perpaipan automasi Python (ArcPy) dan algoritma Pembelajaran Mendalam (*GeoAI U-Net*) untuk perahan data guna tanah berketepatan tinggi daripada imej satelit.

🔍 Methodology & Implementation Framework

[ LAYER 1: MULTI-CRITERIA DECISION MAKING (MCDM-AHP) ]

• Input: Faktor Topografi (DEM), Kecerunan, Jenis Tanih, Sumber Air & Saliran

• Proses: Penilaian Matriks Perbandingan Berpasangan & Pengiraan Nilai Wajaran (Weightage)

↓

[ LAYER 2: GEOAI & DEEP LEARNING EXTRACTION ]

• Input: Imej Satelit & Data UAV Multispektral

• Proses: Latihan Model U-Net + ResNet34 (Google Colab T4 GPU) & Penapisan Hingar Geometri (<30 sqm)

↓

[ LAYER 3: SPATIAL OVERLAY & SUITABILITY MAPPING ]

• Output Akhir: Peta Klasifikasi Kesesuaian Tanah (Sangat Sesuai, Sesuai, Tidak Sesuai)
